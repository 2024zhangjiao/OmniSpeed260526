## ✨ 核心硬核功能

* **方案自主切换**：内置国内腾讯/阿里优质骨干节点及海外 Cloudflare 边缘网络，自由评估本土宽带吞吐或跨境网络质量。
* **资产身份识别**：基于边缘计算，精准抓取公网 IPv4、内网/虚拟网络沙箱地址、ASN 运营商组织特征及物理地理位置。
* **风控纯净度审计**：智能识别网络新宿主分类，判定是否为原生家庭住宅网络或数据中心机房代理（Proxy/Hosting），评估网络摩擦纯净度。
* **智能专家建议**：内置本地风控策略引擎，根据网络环境自动生成生产场景指导——明确“推荐做什么”与“高危不推荐行为告警”。

## 🛡️ 开源纯净宣言

1. **零广告注入**：拒绝市面上测速软件臃肿的开屏弹窗与商业广告。
2. **零隐私持久化**：全前端边缘解算，不设后台数据库，不存储、不追踪使用者的任何 IP 与物理资产隐私。
3. **完全免费**：采用最宽松的 MIT 开源协议，允许全网络自由分发与二次打磨。

## 🛠️ 技术栈
* **Frontend UI**: Tailwind CSS v4 (暗黑极客响应式设计)
* **Core Engine**: Pure JavaScript (WebRTC Sandbox Traversal / Fetch Stream API)
* **Hosting**: GitHub Pages
